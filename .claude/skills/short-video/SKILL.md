# ショート動画作成スキル

長尺素材 → 縦型ショート（9:16 / 1080x1920）への変換パイプライン。
**「尺を縮める」のではなく「1本＝1メッセージに絞り直す」** のが原則。11分のライブは11分ぶんの情報ではなく、ショート3〜5本ぶんのネタが入っている素材とみなす。

---

## 0. 前提の確認（最初に必ずやる）

作業前に以下を確認する。1つでも欠けていたら、**推測で進めずユーザーに確認する**。

| 確認項目 | 具体的に |
|---|---|
| 素材の実体 | 動画ファイルが実際に読めるパスにあるか。クラウド上のフォルダのスクリーンショットは素材ではない |
| インサート素材 | B-roll（写真・別動画）が読めるか。「写真アプリから」はローカル環境でしか成立しない |
| 出力先 | 投稿プラットフォーム（Reels / Shorts / TikTok）と本数 |
| 話者の狙い | 認知拡大か、集客導線か、ファン化か。これでフックとCTAが変わる |

```bash
# 素材の確認
ffprobe -v error -show_entries format=duration,size:stream=width,height,r_frame_rate \
  -of default=noprint_wrappers=1 "$SRC"
```

### macOS で素材を揃える

iCloud Drive のファイルは**実体がダウンロードされていないことがある**（`.icloud` という0バイトのスタブだけが置かれている状態）。作業前に必ず実体化する。

```bash
ICLOUD=~/Library/Mobile\ Documents/com~apple~CloudDocs

# スタブが残っていないか確認（何も出なければOK）
find "$ICLOUD/対象フォルダ" -name "*.icloud"

# 実体をダウンロード
find "$ICLOUD/対象フォルダ" -name "*.icloud" -exec brctl download {} \;
```

**写真アプリのライブラリは直接読めない。** インサート素材は、写真アプリで対象を選択し「書き出す > 未編集のオリジナルを書き出す」で通常のフォルダに出してもらう。パスを推測して探しに行かないこと。

### 環境要件

| 要件 | 確認 / 導入 |
|---|---|
| `ffmpeg` / `ffprobe` | `ffmpeg -version` / macOS: `brew install ffmpeg` |
| 日本語フォント | `fc-list :lang=ja`（macOS はヒラギノが標準で入っている） |
| 文字起こし | `pip3 install faster-whisper`（**必須**。理由は次節） |

> **注意**：文字起こしはモデルを huggingface.co から取得する。ネットワークが制限された環境では失敗するので、**素材とネットワークの両方が揃うマシンで作業する**こと。

## 1. 素材を「読む」— 文字起こしとネタ出し

**この工程を飛ばしてはいけない。** Claude は音声を直接聞けないので、文字起こしがないと「どこにいい発言があるか」が一切分からず、結局は先頭から機械的に切るだけの動画になる。ショートの質はほぼここで決まる。

```bash
python3 scripts/transcribe.py live.mp4
# → live.txt（タイムスタンプ付き本文）と live.json を出力
```

1. 出力された `live.txt` を**全文読む**（要約させない。強い一言は要約で必ず消える）。
2. **独立して成立する話題ブロック**を洗い出す。
3. 各ブロックを次の3軸で採点し、上位を採用する。

| 軸 | 高い例 | 低い例 |
|---|---|---|
| **意外性** | 「電線が爆発した」「イノシシが玄関先まで来る」 | 「自然が豊かです」 |
| **具体性** | 数字・固有名詞・実際に起きた出来事 | 一般論・心構え |
| **自分ごと化** | 視聴者が自分の生活に置き換えられる | 話者の内輪話 |

> **重要**：ライブの冒頭は挨拶と接続確認でほぼ必ず死んでいる。**冒頭から使うな。** いちばん強い発言が何分何秒にあるかを探し、そこを起点に組む。

## 2. 構成を組む — 尺と骨格

**目標尺 45〜75秒。** 迷ったら短いほうを選ぶ。1本1メッセージ。

| 区間 | 尺 | 役割 |
|---|---|---|
| **フック** | 0.0–3.0s | 続きを見る理由をここだけで作る |
| **前提** | 3–10s | 誰が・どこで・何の話かを一瞬で立てる |
| **本編** | 10–55s | 具体例2〜3個。1つあたり10〜15秒 |
| **落ち＋CTA** | 残り5–10s | 言い切って終わる。CTAは1つだけ |

### フックの作り方（最重要）

冒頭3秒で決まる。以下を**すべて**満たすこと。

- **0.0秒から音声が始まっている**（無音・間・「えー」は完全に排除）
- **最も強い発言を切り出して冒頭に置く**（時系列は無視してよい）
- **テロップが画面に出ている**（音を切って見る視聴者が過半数）
- **具体的な単語が入っている**（「大変」ではなく「電線が爆発した」）

フックの型：

| 型 | 例 |
|---|---|
| 異常事態の提示 | 「家の前の電線、爆発したんですよ」 |
| 常識の否定 | 「田舎暮らし＝のんびり、ではないです」 |
| 数字 | 「移住3年で、獣害の被害は年◯回」 |
| 未完の問い | 「これ、何が起きたと思います？」 |

**やってはいけないフック**：挨拶（「こんばんは」）／自己紹介から入る／「今日は〜についてお話しします」という予告／BGMだけで始まる数秒。

### カットの原則

- **無音 0.35秒以上は詰める**（間はリズムを殺す）
- 「えー」「あの」「なんか」「まあ」は削る
- **同一画角が2.5秒以上続いたら画に変化を入れる**（インサート・ズーム・テロップ切替）
- 話が横道に逸れたら容赦なく切る。文脈は視聴者が補完する

`scripts/autocut.py` が無音検出とジャンプカットを行う。

```bash
# 検出のみ（どこが無音か確認）
python3 scripts/autocut.py src.mp4

# 使う区間を切り出しつつ無音を詰める
python3 scripts/autocut.py src.mp4 --start 252 --end 300 --out tight.mp4
```

自動カットは下地。**必ず目と耳で確認し、意味の切れ目でないカットは戻す。**

## 3. インサート（B-roll）を入れる

**語りの画だけで45秒はもたない。** 言葉が指しているものを画で見せる。

- **配置**：その単語が発話された **0.2秒後**に差し込む（先出しはネタバレ、遅れは意味不明）
- **長さ**：0.8〜1.5秒。静止画なら常にゆっくり動かす（Ken Burns）
- **密度**：10秒に最低1回。フック直後には必ず1枚入れる
- **音**：インサート中も**話者の声は途切れさせない**（映像だけ差し替え）

```bash
# 静止画インサート（ゆっくりズーム＝ケン・バーンズ / 1.2秒）
ffmpeg -y -loop 1 -i insert.jpg -t 1.2 \
  -vf "scale=2160:-1,zoompan=z='min(zoom+0.0012,1.12)':d=36:s=1080x1920:fps=30,setsar=1" \
  -c:v libx264 -pix_fmt yuv420p insert.mp4

# 動画インサート（9:16にセンタークロップ）
ffmpeg -y -i insert_src.mov -t 1.5 \
  -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,fps=30,setsar=1" \
  -an -c:v libx264 -pix_fmt yuv420p insert.mp4
```

インサート素材が用意できない話題は、**その話題自体を採用しない**。言葉だけで押し切ると離脱する。

## 4. テロップとセーフゾーン

### セーフゾーン（1080x1920 基準）

プラットフォームUIに隠れる領域には**絶対に文字を置かない**。

| 領域 | 範囲 | 隠れるもの |
|---|---|---|
| 上部 | y = 0 〜 **250px** | ステータスバー／アカウント名／「ライブ」表示 |
| 下部 | y = **1500px** 〜 1920 | キャプション／音源名／シェアUI |
| 右側 | x = **940px** 〜 1080 | いいね・コメント・保存ボタン |

→ **テロップ安全域は x: 80–940px、y: 250–1500px。**
→ 右側UIを避けるため、テロップの水平中心は **x = 510**（画面中心より30px左。目視ではズレを感じない）。
→ **メインテロップの基準位置は y ≈ 1300px**（顔にかぶらず、下部UIにも飲まれない）。

### テロップ設計

- **1画面 最大13文字 × 2行**。超えたら分割する
- 話速に追従させる。1テロップの表示は**1.2〜2.5秒**
- **白文字＋黒縁（縁幅 6〜8px）＋半透明の座布団**。背景が何色でも読める状態にする
- フックのテロップだけ **1.4倍サイズ＋キーワードを色替え**（黄色）にして視線を止める
- 句読点は入れない（スペースか改行で代用）。読点は視線を止める

`scripts/burn_telop.py` が ASS 字幕を生成し、セーフゾーンを自動検証する。

```bash
python3 scripts/burn_telop.py telop.json --video base.mp4 --out final.mp4
```

`telop.json` の形式：

```json
[
  {"start": 0.0, "end": 2.6, "text": "家の前の電線が\n爆発しました", "style": "hook", "highlight": "爆発"},
  {"start": 2.6, "end": 5.0, "text": "移住3年目の\nリアルな話です", "style": "main"}
]
```

## 5. 書き出し

```bash
ffmpeg -y -i edit.mp4 \
  -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,fps=30,setsar=1" \
  -c:v libx264 -profile:v high -preset slow -crf 20 -pix_fmt yuv420p \
  -c:a aac -b:a 192k -ar 48000 -movflags +faststart out.mp4
```

- 音声は **-14 LUFS** 前後に正規化（`loudnorm=I=-14:TP=-1.5:LRA=11`）。ライブ録音は音が小さいことが多い
- BGMを入れる場合は **話者の声より 18dB 以上下げる**。ショートでBGMが勝つと内容が入らない

## 6. 【必須】注目・認知チェック

**書き出したら必ずこのゲートを通す。** 1つでも ✗ があれば編集に戻る。報告時はこの表を添付する。

### A. 冒頭3秒（最重要・ここが落ちたら他は無意味）

- [ ] 0.0秒時点で**音声が鳴っている**（無音スタートではない）
- [ ] 0.0秒時点で**テロップが出ている**
- [ ] 3秒以内に**具体的な名詞または数字**が出る
- [ ] 挨拶・自己紹介・予告で始まっていない
- [ ] **音を消して冒頭3秒だけ見て、続きが気になるか**

### B. 離脱耐性

- [ ] 2.5秒以上、画に変化のない区間がない
- [ ] 0.35秒以上の無音がない
- [ ] 10秒ごとに「引き」（新情報・意外な事実・画の切替）がある
- [ ] 全体尺が75秒以内

### C. 可読性

- [ ] 全テロップが安全域（x:60–860 / y:250–1500）に収まっている
- [ ] 1画面13文字×2行を超えていない
- [ ] 背景が明るい場面でも白文字が読める
- [ ] **音声なしで最後まで見て、内容が理解できる**

### D. 認知獲得

- [ ] 「誰の・どこの話か」が15秒以内に分かる
- [ ] 保存・シェアしたくなる**持ち帰り情報**が1つ以上ある
- [ ] CTAが1つに絞られている（複数出すと全部無視される）
- [ ] 最後が言い切りで終わっている（尻すぼみ・「という感じですね」で終わらない）

### 自己採点

各項目1点（全17点）。**14点未満は投稿に値しない** — 該当箇所を修正してから再チェックする。
点数と、落ちた項目・その対処をユーザーに必ず報告すること。

## アンチパターン

| ✗ やりがち | ○ 正しくは |
|---|---|
| 文字起こしせずに切り始める | 先に全文を起こし、強い発言の位置を特定してから組む |
| 文字起こしを要約してから読む | 全文を読む。強い一言は要約で必ず消える |
| 長尺の冒頭をそのまま使う | 最も強い発言を探して冒頭に持ってくる |
| 尺に合わせて均等に間引く | 1本1メッセージに絞り、他は別の本にする |
| テロップを画面中央〜下端いっぱいに置く | y:1150–1400px の安全域に置く |
| 全発言をテロップ化する | キーワードを拾い、読ませすぎない |
| BGMで盛り上げようとする | 発言の中身で持たせ、BGMは-18dB以下 |
| インサートを飾りとして入れる | 発話の0.2秒後、言葉が指すものを見せる |
| チェックせずに納品する | 17点満点のゲートを通してから出す |
